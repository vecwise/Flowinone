# 多 UI 比較

從「設定 → UI Lab」進入 `/ui-lab/`，比較 baseline、curator、workbench 三套桌面 UI。三套共用 [瀏覽、詳情與管理頁型](ui-consolidation.md)，每套各有三個比較入口；同一頁型使用相同條件與現有樣本，僅 `ui` 不同。沒有樣本時提供準備入口。

| UI | 瀏覽 | 詳情 | 管理 |
| --- | --- | --- | --- |
| 目前基準 | 緊密縮圖網格、精簡搜尋列 | 主內容與接著看雙欄 | 來源卡片與維護分區 |
| 視覺策展 | 暖白畫廊、影像優先 | 寬幅內容、相關項目置底 | 來源展卡、功能分區 |
| 素材工作台 | 緊湊工具列、密集網格 | 主內容與資訊並排 | 側邊功能列、緊湊來源狀態 |

僅設計及驗收桌面，使用 1280×900、1440×900 的滑鼠與鍵盤操作。三套 UI 的收藏瀏覽皆提供網格與連續模式，媒體行為見 [網格與連續模式](gallery-reading.md)。來源與維護工具預設收合；重爬或恢復未完成工作時，進度面板自動展開。

## 媒體分類與縮圖比例

搜尋列提供「全部、影片、圖片、漫畫／圖集、網頁／其他」。`media` 在 SQL 分頁前篩選，總數、快取、常用條件與相關推薦使用相同條件；切換分類會保留其他條件並清除舊分頁。

來源的 image／video／album 類型優先。一般網址內建辨識 YouTube watch／shorts 與 youtu.be；其他網站預設為網頁，可透過 [本機擴充](../README.md#書籤縮圖與本機擴充) 加入分類規則。分類不更改來源資料，也不觸發抓取。

「⋯ → 縮圖比例」提供依內容、橫式 16:9、直式 3:4、方形 1:1。圖片保留完整畫面，影片與圖集封面使用 cover。連續模式保留媒體原比例，隱藏縮圖比例控制；切回網格恢復選擇。

`shape` 只屬呈現，不過濾資料或加入查詢簽章；沿用網址、分頁與詳情返回連結。來源篩選則使用全站 cookie，頁內清除條件仍保留來源選擇。

## 切換與狀態

「設定 → 外觀」可即時切換 UI，不重新建立內容，因此草稿、勾選、展開狀態、預覽及媒體元素留在原頁面。選擇保存在 `?ui=...`，不寫全域偏好，讓分頁能獨立比較。

UI 隨站內頁面連結、表單與 HTML 轉址延續，保留重複查詢參數、錨點及 `return_to`；Lab 固定比較連結不被覆寫。未知 UI 或退役的 `ui=reader` 回到基準。舊 `view=reader` 則對應連續模式。

`ui` 不屬於 CatalogQuery，也不附加到 API、靜態檔、媒體串流或外部連結。跨來源 URL 不能作為 Lab 返回頁。

## 維護位置

- `src/flowinone/web/ui_variants.py`：方案登錄、伺服器初始選擇、HTML 連結、轉址與 Lab 樣本。
- `static/css/ui_pages.css`、`ui_variants.css`、`catalog_compact.css`：共用頁型、方案樣式與桌面層級。
- `static/js/ui_switcher.js`：即時切換與 URL／表單同步。
- `static/js/navigator_controls.js`、`compact_menus.js`：即時排序、搜尋草稿與選單鍵盤操作。
- `templates/components/_ui_picker.html`、`_ui_lab.html`：外觀選單與比較入口。

新增正式 HTML route 時，同步更新 `UI_ENDPOINTS`、前端 `isPagePath` 與路由導覽。API／檔案路由維持獨立；新增 UI 優先共用 token、頁型與既有 data 屬性。

測試應涵蓋三套 UI 的頁型、草稿、來源條件、排序、分頁、預覽、Esc 焦點返回，以及 API／外部連結邊界。執行方式見 [README 測試](../README.md#測試)；真實桌面布局另以隔離資料與上述視窗尺寸驗證。
