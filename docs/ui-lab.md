# 多 UI 比較

從導覽列「設定 → UI Lab」進入 `/ui-lab/`。保留目前基準 `baseline`、視覺策展 `curator`、素材工作台 `workbench` 三套桌面 UI，共用 `browse.html`、`detail.html`、`manage.html` 三個頁型，Lab 本身使用管理模板。

每套提供瀏覽、詳情、管理三個新分頁連結，共 9 個比較入口。同一頁型使用同一個網址條件／真實樣本，僅 `ui` 不同；詳情優先選 Resource，其次是可用媒體，沒有樣本時明示準備入口。也可用任一方案開啟進 Lab 前的頁面。

| UI | 瀏覽 | 詳情 | 管理 |
| --- | --- | --- | --- |
| 目前基準 | 緊密縮圖網格、精簡搜尋列 | 主內容與接著看雙欄 | 來源卡片與維護分區 |
| 視覺策展 | 暖白畫廊、影像優先的緊密網格 | 寬幅內容、相關項目置底橫排 | 來源展卡、功能分區 |
| 素材工作台 | 共用精簡工具列、密集網格 | 主內容與資訊並排 | 側邊功能列、緊湊來源狀態 |

## 桌面與共用卡片

目前只設計及驗收桌面瀏覽，以 1280×900、1440×900 的滑鼠與鍵盤操作為準。後續需求也沿用此範圍，除非使用者明確重新納入手機版。

三套 UI 的日常卡片只顯示縮圖、最多兩行標題、一行來源／網站資訊，卡片間距 8–10px、文字區內距 6–8px。愛心與更多資訊使用圖示按鈕，保留完整可及名稱及鍵盤操作。說明、命中原因、全文摘錄、資料夾、標籤、開站與縮圖維護收在「更多」。主題、來源狀態與批次縮圖工具預設收合；啟動重爬或恢復未完成工作時，進度面板自動展開。

網格／清單仍是同一 UI 內的檢視模式，清單中的圖片保留完整比例。媒體分流與比例比較沿用同一瀏覽模板，圖集連續閱讀仍待下一階段評估。

## 媒體分流與縮圖比例

收藏搜尋表單提供「全部、影片、圖片、漫畫／圖集、網頁／其他」五個內容選項。改變分類會提交目前搜尋、來源、資料夾、標籤、排序等條件，清除上一分類的精確類型與分頁游標；精確類型仍可在「篩選」面板指定。分類不額外顯示可能與目前條件不一致的全站數字。

`media` 在 SQL 分頁前篩選；總數、快取、常用條件與相關推薦使用相同條件。來源媒體類型優先，網址內建辨識 YouTube watch／shorts 與 youtu.be；其他網站可透過本機擴充加入規則。分類不更改來源資料，也不觸發抓取。

結果右上「⋯ → 縮圖比例」可立即切換：

| 選項 | 呈現 |
| --- | --- |
| 依內容 | 全部／網頁用等高 4:3，影片 16:9，圖片與圖集 3:4；舊 image/video 精確篩選也適用 |
| 橫式 | 統一 16:9 |
| 直式 | 統一 3:4 |
| 方形 | 統一 1:1 |

圖片一律 contain，保留完整畫面；影片及圖集封面使用 cover，手選不相符比例時會裁切。來源資料夾若這一批全為同類媒體，依該媒體決定自動比例；包含資料夾／標籤的混合批次仍為 4:3。清單模式保留圖片原比例閱讀，暫時隱藏縮圖比例控制；切回網格會恢復選擇。

`shape` 只屬呈現，不加入查詢簽章或 API 過濾。選擇留在網址、搜尋表單、下一批與詳情返回連結，不重新建立卡片；切換 UI 保留比例與所有瀏覽條件。沒有使用全域 shape 偏好，也沒有新增模板或手機版。

## 切換與狀態

導覽列「設定 → 外觀」提供介面選單；收藏預覽沿用同一方案。切換會更新根元素的 `data-ui`，不重新載入或重建內容，因此未送出文字、勾選、檔案輸入、展開狀態、預覽與媒體元素仍留在原頁面。不同版面會改變內容位置與頁面高度。

選擇記在 `?ui=...`，保留其他參數（包含重複的來源／標籤、游標、seed、context、view）、錨點及內層 `return_to`。目前 UI 隨一般站內連結、GET／POST 表單及 HTML 轉址繼續；Lab 的固定比較連結不被覆寫。沒有 `ui` 時使用基準，未知值與已移除的 `ui=reader` 也回到基準。不寫全域 UI 偏好或 cookie，讓分頁可以獨立比較。舊的 `view=reader` 是清單模式，仍保留相容。

`ui` 不屬於 CatalogQuery，不進查詢簽章或 API payload。靜態檔、媒體串流、資源附件、API 與外部連結不附加 UI 參數。跨來源 URL 不能作為 Lab 返回頁。

## 維護位置

- `src/flowinone/web/ui_variants.py`：三套方案登錄、伺服器初始選擇、HTML 連結與轉址、Lab 樣本。
- `static/css/ui_pages.css`：共用卡片與三頁型規則；`static/css/ui_variants.css`：方案配色及桌面布局。
- `static/js/ui_switcher.js`：即時切換、URL 與表單同步、動態預覽連結。
- `templates/components/_ui_picker.html`：設定內的外觀選單。
- `templates/components/_ui_lab.html`：比較卡與 9 個真實入口。

新增正式 HTML route 時，同步補上 `UI_ENDPOINTS`、前端 `isPagePath` 與測試導覽；不要把 API 或檔案路由加入呈現層名單。新增 UI 優先使用 token 與三頁型的布局規則，保留共用元件的 data 屬性與操作契約。
