# Gallery 網格與連續模式

- 日常檢視為「網格／連續」。`view=list` 與 `view=continuous` 都進入連續模式，保留舊連結與偏好相容性。
- 網格移除卡片外框與陰影；自動比例的單張圖片依完整比例排列，保留 DOM 與鍵盤順序。
- 名稱可選自動／全部顯示／全部隱藏。自動模式隱藏單張圖片名稱，保留影片、圖集、資料夾與一般網頁名稱；操作在滑鼠移入或鍵盤聚焦時顯示。
- 連續模式以 900px 置中呈現圖片與影片，保留原比例，不限制長圖高度，不顯示名稱或卡片操作。影片使用原生控制，同時只播放一支。
- 接近畫面才解析原圖／影片來源；媒體沿用來源可用性與檔案存取邊界，串流支援 Range。
- 接近底部自動追加下一批，保留篩選、排序、seed、UI 與返回條件；失敗後顯示手動重試。切回網格仍可操作已追加項目。
- sessionStorage 保存批次識別、捲動位置與圖片比例；返回時依目前分頁鏈恢復，不保存媒體或 HTML。
- Eagle 圖集由直接含圖片的資料夾產生，進入後可混排同資料夾的圖片與影片。只有影片的資料夾不會成為圖集。
- 一般書籤仍提供封面與原站入口，不將縮圖視為完整圖集，也不擷取外站媒體。

## 驗證方式

桌面以 baseline／curator／workbench 三套 UI、1280×900 與 1440×900、滑鼠及鍵盤操作為準。使用臨時資料庫、合成橫直長圖與可解碼影片，檢查：

1. 網格比例、名稱選項、鍵盤順序與水平溢出。
2. 連續模式的原圖、長圖與影片播放，以及本機／Eagle 圖集混排。
3. 自動追加、最後一批、HTTP 失敗重試與重複項目。
4. 追加項目的預覽、完整詳情、返回條件及捲動位置恢復。

自動測試見 `tests/test_continuous_gallery.py`、`tests/test_eagle_albums.py` 與 `tests/browser/`；執行方式見 [README 測試](../README.md#測試)。更新 Python 或模板後需重啟 Web，變更本機擴充則需重啟 Web 與 Worker。
